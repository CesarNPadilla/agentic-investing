# ADR-018: Offline Backtesting & Strategy Validation Engine v0.1

Date: 2026-09-30. Internal research service only; production trading disabled.

Research -> Thesis -> Opportunity -> Strategy -> Backtest -> Validation -> Paper Eligibility.
This implementation stops at eligibility reporting. It creates no paper or live broker orders.

1. Add `backtesting/` alongside the legacy `simulation/` API. Preserve old workflows;
   legacy results are not silently converted into new validation evidence.
2. Reuse concrete LongTermStrategy/SwingStrategy, OpportunityEngine, independent
   strategy replay, TradeProposal, deterministic risk, portfolio records and indicators.
   The only strategy extension is an explicit historical-replay option permitting a
   later-authored version to run against old data. Retain its creation timestamp and
   flag retrospective definition for validation review. Current workflows retain defaults.
3. Providers return versioned archives with availability timestamps. Materialize views
   containing only available rows; never give a strategy the full archive. Check nested
   research/source timestamps. Raw execution prices and adjusted indicator vintages
   are separate. Reject opaque historical reference dictionaries.
4. Internal next-session-close execution uses adverse slippage, half-spread and fees.
   Independent signal review and fill-time risk both apply. Default human-review handling
   skips fills; explicit assumed approval is simulation-only. Preserve proposal limit
   prices; market accounting capability is not permission to convert limit proposals.
5. Keep the current policy intact: USD 160 attributed-capital ceiling, whole-share buys,
   no borrowing/shorting and all unknown controls fail closed. Configurable research
   starting cash is synthetic and distinct from actual portfolio/experimental funding;
   it does not enlarge the policy's investable experimental sleeve.
6. Support split/reverse-split quantity and cost-basis accounting and explicitly dated
   same-close cash dividends. Reject unsupported dividend payment schedules, symbol
   changes, delistings and mergers. Never invent disposal proceeds or ignore actions.
7. Existing strategies do not authorize sells, and swing review requires 60 forward
   sessions. Those restrictions remain visible, even when they prevent a useful backtest.
   Sell/fractional accounting is tested independently; it is not reachable as an approved
   trade under this policy. A separate reviewed policy change is needed to remove this
   limitation. Backtests never manufacture forward validation evidence.
8. Store immutable experiments and strategy definitions atomically using additive SQL
   tables. Persist complete configuration, dataset, decisions, fills, curves and report.
   Deterministic IDs and Decimal accounting make identical inputs replay identically.
9. Validation is separate from completion. Missing mandatory gates remain UNSET;
   synthetic runs cannot qualify. Explicit nonoverlapping holdout folds support a
   walk-forward workflow without fitting, optimization or automatic selection.
10. No broker dependency, credential, HTTP route, worker or scheduling capability is
    introduced. External text stays inert evidence. Production authorization and the
    existing independent qualification gate remain unchanged.

Provider provenance, calendar completeness, genuine historical theses, revision vintages,
historical universes, liquidity and operational database validation remain external gaps.
