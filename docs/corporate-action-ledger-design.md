# Versioned corporate-action ledger v0.5

The provider-neutral model is `LedgerEvent` in `experiment_lab/corporate_action_reconstruction.py`. `CorporateActionProvider` remains the read-only provider contract; `AlpacaCorporateActionProvider` now reads the API's nested `corporate_actions` response. The immutable `CorporateActionRepository` keeps event versions and refuses a conflicting duplicate. A correction names the exact version it supersedes, must increase its version number, and cannot change security identity or event type. The immutable raw Alpaca response and normalized ledger live outside the repository.

Each ledger entry carries a pinned security ID, source symbol, event type, provider and source ID, declaration date if supplied, public-availability evidence if proven, ex/record/payment/effective dates, amount or new-shares-per-old-share ratio, currency, retrieval time, raw reference and digest, version, supersession link, quality state, and explicit term-verification state. GOOG and GOOGL are separate share classes with different IDs. Unsupported or unattributed events remain in the raw snapshot and exclusion audit; they are never silently assigned to a requested security.

`knowledge_state` reports `EVENT_KNOWN_AT_T`, `EVENT_NOT_YET_KNOWN_AT_T`, or `EVENT_AVAILABILITY_UNCERTAIN`. A declaration date, ex-date, or retrospective provider row does not become a public timestamp. `economic_state` independently reports `EVENT_ECONOMICALLY_EFFECTIVE`, `EVENT_NOT_YET_EFFECTIVE`, or `EVENT_TERMS_UNVERIFIED`. An event can have documented accounting effects while remaining unavailable as a historical research signal.

The deterministic quality gate in `qualify_gates` checks provenance, term verification, split/dividend completeness, publication classification, effective dates, versions, reproducibility, raw immutability, independent reconciliation, VOO methodology, look-ahead, and OOS isolation separately. Accounting qualification does not require signal-publication proof; signal qualification does. **Both fail in the live v0.5 review.** Exploratory output is labeled nonqualifying and cannot promote itself or start paper validation.
