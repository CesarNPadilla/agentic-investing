# ADR-013: Separate portfolio ownership, research scope and agent capital

Status: accepted and implemented for read-only research, 2026-09-29.

## Problem

The earlier experimental USD 160 total-exposure check incorrectly treated the user's
existing portfolio as agent experimental capital. Ownership outside the AAPL/MSFT/SPY
purchase list must neither prevent holdings analysis nor imply liquidation.

## Decision

Keep three independent concepts: `portfolio_holdings` is the complete broker inventory;
`research_universe` permits additional research/monitoring; `new_purchase_allowlist`
controls creation of research BUY proposals. Holdings are always analyzable. Neither
holding nor researching a security grants new-purchase permission.

Replace whole-portfolio USD 160 controls with `agent_experimental_capital_limit = 160`.
Only an explicitly reviewed allocation of quantities, remaining acquisition cost and
open order IDs consumes that limit. No ownership inference from symbol, portfolio size
or account ID alone. Unknown attribution remains unknown and blocks hypothetical approval.
Funding checks still reserve all outstanding buys against the target account's settled
cash; existing orders cannot be ignored just because they are outside the experiment.

Whole-portfolio metrics and >20%/>30% concentration warnings are informational. No
automatic sales, rebalancing, cancellation or order changes may result. Position theses
are revisioned local research records with immutable original rationale and append-only
agent review history. Unknown investment decisions remain null.

Extend authenticated broker reads and persist normalized observations separately from
execution. Webull field mappings use official OpenAPI definitions and installed SDK read
methods. Exhaust pagination, bound queries, preserve unavailable values and distinguish
retrieval time from market-data time. Cash activities are not a complete share/settlement
ledger, and independent reads are not atomic. Reconciliation exposes those gaps instead
of declaring a false pass. Available metrics remain useful even while reconciliation is
incomplete. See the [contract and limitations](investment-policy-portfolio.md).

## Consequences

Schema v3 rejects old policy names rather than silently changing their meaning. New
observation/thesis/evaluation tables preserve old evidence untouched. Additive local
bootstrap works with the application database; reviewed production migrations remain open.
Research BUY proposals and all new analysis code have no broker mutation capability.
The existing synthetic execution subsystem remains separate and disabled by default.

Verified source references: Webull [positions](https://developer.webull.com/apis/docs/reference/account-position/),
[balances](https://developer.webull.com/apis/docs/reference/account-balance/),
[open orders](https://developer.webull.com/apis/docs/reference/order-open/) and
[cash activities](https://developer.webull.com/apis/docs/reference/trade-cash-activity-by-type/).
The equivalent `.md` pages publish machine-readable field schemas; no private account
payloads or credentials were accessed to establish these mappings.
