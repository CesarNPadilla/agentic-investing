# Guardian recovery inspection

The staged read-only inspector classifies local retained review evidence as: absent evidence with freshness unestablished; retained intent requiring reconciliation; matching owner consumption awaiting confirmation; or matching retained review evidence with no reset authority. It verifies the retained signature, envelope, receipt digest, request identifiers, preparation/consumption ordering, confirmation binding and optional expected intent digest. Duplicate keys, nonfinite values, altered confirmations, missing prior anchors and observed evidence changes fail closed.

Inspection never repairs state, retries consumption, creates a new review, deletes references or grants recovery/reset/trading authority. Without a supplied expected intent digest, it does not claim an independently anchored history. A supplied digest must come from separately protected trusted configuration; matching a caller-provided digest alone does not establish that protection. Missing all records never proves a fresh usable context. The diagnostic is a local snapshot, not a proof of filesystem power-loss durability, trustworthy clocks, broker accounting completeness or immutable storage against a compromised guardian.
