# Independent paper trading-status controls

Implemented an isolated status-event model and fail-closed transition diagnostics against [Alpaca's documented status channel](https://docs.alpaca.markets/us/docs/real-time-stock-pricing-data). Status codes are tape-specific: CTA tapes A/B recognize halt/LULD and trading resume; UTP tapes C/O recognize halt/pause and trading resume. Quotation resumption alone and unknown codes remain UNKNOWN. Free-text status descriptions are ignored; they cannot instruct the agent or grant approval.

Events require the correct symbol/type/tape, aware event/receipt times and matching connection epoch. Future/wrong-symbol messages reject. Out-of-order messages, same-timestamp conflicts and disconnects invalidate continuity. Exact semantic replay does not refresh evidence. A new connection requires bootstrap qualification; further status events cannot silently clear prior continuity loss. A trading-resume observation is not order permission: initial source bootstrap and stream health always remain unqualified in this component. No arbitrary stale-status interval was invented, because statuses need not emit repeatedly during an unchanged active market; continuous transport health still needs implementation.

Validation: 10 new tests, 128 targeted paper-control tests pass. Ruff checks, [status JSON](examples/alpaca-paper-month/status-controls.json), source digests and git diff --check pass. Tests cover tape-specific codes, quote-only resume, disconnect/epoch rejection, out-of-order and equal-time events, duplicates, future timestamps and symbol mismatch. No actual status stream connected or entitlement/bootstrap evidence was obtained; no execution gate is cleared by fixture tests.

Next: integrate and qualify the real stream's subscription/authentication, initial status and transport continuity; resolve the pending clock-source/error-bound human decision and qualify actual clock uncertainty; then integrate durable account/loss/reset/order runtime. Paper settlement approval remains recorded. The month-long trial is unstarted, 2026 OOS sealed and live execution disabled.
