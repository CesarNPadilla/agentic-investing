# Guardian host configuration contract

The staged parser accepts at most 32 KiB of exact, externally pinned JSON bytes. Its external configuration SHA-256 and installed release SHA-256 must come from independently protected deployment state; reading either expected hash from the configuration would defeat the binding. This module does not read files, create a host or establish filesystem trust.

A configuration binds one UUID4 provisioning identity, distinct local Windows guardian/owner SIDs, the installed release digest, one current review envelope and its matching public WebAuthn credential. Its fixed paths are `C:\ProgramData\AgenticInvestingGuardian\References\Review-<provisioning UUID>` and the separate owner journal `C:\ProgramData\AgenticInvestingPaper\OwnerControl\Review-<provisioning UUID>\review.sqlite`. Alternate roots, UNC/device paths, traversal and extra path components fail the exact layout check. The process deadline is 15 seconds; reset, execution and trial flags must be explicit JSON false values, without scalar coercion.

Configuration parsing rejects duplicate keys at all nesting levels, nonfinite values, unknown fields, mismatched release or public credential, repeated identities, future/expired review contexts and changed pinned bytes. Reference validation checks exact paths, envelope digest and public credential bytes. Its result explicitly leaves filesystem protection and process identity unqualified. No private signing material belongs in this configuration.
