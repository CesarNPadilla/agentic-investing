# Paper preparation - activity acquisition and fill replay

Added bounded read-only paper activity pagination and deterministic whole-share FILL reconciliation. The reader uses the [Trading API activities endpoint](https://docs.alpaca.markets/us/reference/getaccountactivities-2), explicit aware after/until bounds, ascending direction, 100-row pages and at most 100 pages. It rejects repeats/duplicate IDs, malformed pages, future cutoffs and HTTP failures without redirects or retries. Exhausting pagination is not an account snapshot, publication-completeness guarantee or settlement proof; delayed activities require later overlapping acquisition and identity reconciliation. Time filters are not settlement-date filters.

Replay validates symbol/side, positive finite quantities/prices, aware execution time, cumulative quantity and order identity. It reconstructs shares and trade cash from an explicit opening ledger, comparing closing shares and cash. Missing prior order fills, unexplained shorts, window violations, cash/position mismatches and unmapped non-FILL activities block. It does not manufacture fees or map unreviewed external flows. FEES_AND_EXTERNAL_FLOWS_UNRECONCILED and SETTLED_CASH_UNVERIFIED always remain. These are independent pure replay checks, not the existing portfolio reconciliation contract's complete trusted snapshots.

A real read of the dedicated account's last 24 hours returned zero activities with exhausted pagination. A fresh account check still shows $1,000 equity/cash and empty inventory. No opening execution ledger, midnight baseline, actual fill or settlement was inferred from empty data. No raw activity/account data or credentials were persisted in repository artifacts.

Validation: 11 new acquisition/replay tests and 83 prior targeted controls tests pass (94 total). Partial fills, duplicates, fractional-share rejection, missing cumulative fill history, unknown activities, replay bounds, mismatches, repeated pagination and HTTP failures are covered. Ruff checks pass; [status JSON](examples/alpaca-paper-month/fill-preparation-status.json), source digests and git diff --check pass.
