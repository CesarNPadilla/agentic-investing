# ADR-028: separate risk approval decisions from implementation and execution

Status: v1.0.1 decision package awaiting human action.

Freeze the v1.0 proposal as source evidence. Add a versioned decision register with source digests and initially `PENDING` human fields. Keep capital ceiling, actual funding, and environment authorization separate. Keep sleeve and whole-account controls independent. A future authorization to implement selected risk controls does not authorize forward paper or live execution. Unknown policy or critical evidence fails closed; no automatic liquidation or LLM kill-switch reset. No current policy or code is modified by this ADR.
