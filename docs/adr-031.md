# ADR-031: start independent v1.1 work with isolated synthetic sleeve diagnostics

Status: v1.1a implemented; runtime integration and overall v1.1 incomplete.

Use approved N01–N10 and conditional AUTH-V11 plus the owner's instruction to proceed for a bounded independent implementation. Strict synthetic schemas and a pure deterministic diagnostic implement approved sleeve mathematics, reject missing evidence and expose replayable reason codes. All outputs hard-disable execution and explicitly withhold whole-account qualification. Latch/reset indications do not mutate operational state.

Do not infer missing account limits, sources, owners or funding. Keep existing runtime policy/risk evaluation, strategies and historical evidence unchanged. Persistent baseline/kill-switch behavior, reservations, trusted integrations and whole-account controls remain separate gated workstreams. See [review 011a](human-review-011a.md).
