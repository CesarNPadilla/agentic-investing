Status: v1.0.2 reconciliation complete; 25 owner decisions pending.

Preserve v1.0 and v1.0.1 as immutable proposal evidence. Create a v1.0.2 snapshot using existing stable IDs and decision states, linked by SHA-256 to those sources and to the verbatim original user instruction and message identifier. Record only N01–N10 as APPROVE_AS_PROPOSED / APPROVED_BY_HUMAN; retain original proposal_version and numerical semantics, null identity/timestamp fields, inactive controls and unresolved dependencies. This is attributable conversational policy-design evidence, not an authenticated activation artifact.

Keep all other 25 entries PENDING, including separate CAP-A, CAP-B, CAP-C and AUTH-V11. Prioritize independent account loss and portfolio exposure, trusted evidence, ownership and exceptions in the owner review.
