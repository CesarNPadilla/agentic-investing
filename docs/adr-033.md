# ADR-033: qualify reservation lifecycle with isolated fixed synthetic budgets

Status: v1.1c SQLite synthetic lifecycle foundation implemented; PostgreSQL qualification pending.

Serialize acquisition-cost reservations against explicit fixed cash and sleeve budgets. Bind intent to proposal identity/digest, preserve partial-fill commitments, hold unknown/pending/unverified status, and release only verified unfilled terminal amounts. Retain filled costs as consumed capacity. Replay lifecycle and budget invariants atomically and block on missing/inconsistent storage.

This isolated store is not integrated with v1.1b latch state, risk checks, broker evidence or application databases. PostgreSQL serializable qualification, atomic cross-control integration, marked exposure and account/symbol inventory remain separate work. No execution authorization or actual funding is inferred. See [review 011c](human-review-011c.md).
