# Paper preparation - NYSE session calendar

Implemented an isolated bounded NYSE equity schedule from the [official holiday and hours publication](https://www.nyse.com/trade/hours-calendars), reviewed October 5, 2026. [Versioned calendar](../conf/nyse-calendar-2026.json) covers January 1 through December 31, 2026, including all ten published holidays and the November 27/December 24 1 p.m. Eastern early closes. Regular sessions use 9:30 a.m. through 4 p.m. America/New_York. Other years require a new reviewed artifact; dates outside coverage raise a coverage error or return a blocking diagnostic.

The adapter returns schedule sessions with version and source-file digest. Entry-time schedule checks include the open and exclude the close, reject naive timestamps and use the New York date/DST offsets. Next-trading-day lookup skips explicit holidays/weekends and refuses to guess beyond coverage, including at year end. This supplies a calendar primitive for the owner-approved next-trading-day reset prerequisite; it performs no reset and does not yet connect to durable reset state.

This artifact is a manually curated published schedule, not a fetched raw-page digest or an extraordinary-closure monitor. The source-file digest detects package changes; it does not authenticate the website or prove absence of an emergency closure. A successful scheduled-hours diagnostic never authorizes orders or establishes broker/security status, trusted clock, data freshness or full calendar runtime qualification. Execution remains unavailable.

Validation: 15 new calendar tests, 67 targeted calendar/quote/preflight/readiness tests passed. Tests cover every published holiday, early-close/open boundaries, July observed-holiday weekend, Thanksgiving next session, year-end coverage, DST and malformed closure conflicts. Both JSON artifacts validate; source digests and git diff --check pass. Existing provider files, historical/OOS/strategy data, runtime configuration and execution flags are preserved.
