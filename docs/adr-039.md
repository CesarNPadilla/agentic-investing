# ADR-039 - keep daily whole-account loss basis fixed and exposure capacity current

Status: v1.1i isolated whole-account diagnostic implemented; runtime integration pending.

Use owner-confirmed 1% start-of-day account equity for daily loss and 100%/10% current account equity for gross/per-security exposure. Include pending/proposed buys and fees/cash constraints, remove external flows from daily P&L and block incomplete evidence. Keep the account controls separate from sleeve controls.

Apply owner-selected America/New_York calendar midnight and existing breach treatment: retain/report, block further buys in the security, require human review, no liquidation. Record denominator timing assent with provenance and update current readiness text while preserving historical snapshots. Authenticated reset, check frequency, diversification, operational authority and actual data evidence remain required. See [review](human-review-011i.md).
